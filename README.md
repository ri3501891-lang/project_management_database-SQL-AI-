# IT Project Management DB

PostgreSQL を使って、ITプロジェクト管理システムを題材に DB設計・制約・インデックス・SQLレビューを練習する学習用リポジトリです。

このリポジトリでは、AIとの対話を通じて改善していく過程も記録しています。

## 学習テーマ

- 要件整理
- エンティティ・リレーション設計
- カラム・型・制約の検討
- インデックス設計
- 悪いSQLのレビューと改善

## ドキュメント

- [要件整理・エンティティ・リレーション整理の振り返り](docs/requirements-er-review.md)
- [カラム・型・制約の振り返り](docs/columns-types-constraints-review.md)
- [インデックス設計の振り返り](docs/index-review.md)
- [SQLレビュー（悪いクエリ5本）の振り返り](docs/query-review.md)

## 方針

このリポジトリは、最初の案と修正版の両方を残し、どこをどう修正したかを説明できるようにすることを目的としています。  
完成した設計だけでなく、途中での誤りや迷った点も学習ログとして残します。
